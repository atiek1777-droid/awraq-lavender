# أوراق لافندر — الموقع

## 1) عدّل بياناتك (ملف واحد فقط)
افتح `lib/site.ts` وضع:
- أرقام واتساب الفروع (الصيغة الدولية بدون + مثل 966500000000)
- رقم واتساب عام (اختياري) — يجعل الزر الرئيسي يفتح محادثة مباشرة
- حساب سناب (اختياري)

## 2) التشغيل والبناء
    npm install
    npm run dev       # للمعاينة http://localhost:3000
    npm run build     # ينتج مجلد out/

## 3) الرفع
- **أي استضافة:** ارفع محتويات مجلد `out/` إلى public_html.
- **Vercel / Netlify / Cloudflare Pages:** ارفع المشروع كما هو (أو اسحب مجلد out).

الصور في `public/images`، والخطوط محلية (لا تحتاج إنترنت أثناء البناء).
