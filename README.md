# أوراق لافندر - Awraq Lavender

## التشغيل محلياً
    npm install
    npm run dev        # http://localhost:3000

## الرفع على الإنترنت
    npm install
    npm run build      # ينتج مجلد out/

ارفع **محتويات مجلد out/** إلى الاستضافة (public_html أو ما يعادله)،
أو اسحب مجلد out على Netlify / Cloudflare Pages / Vercel.

## قبل الرفع عدّل
components/LandingSection.tsx:
- رقم واتساب WHATSAPP_URL
- روابط إنستغرام وسناب وتيك توك والموقع
